# Подключение Barcode-list.ru к «Телу»

Состояние: приложение и серверная часть подготовлены. Сервер НЕ размещён, автоматическое подключение НЕ включено.

Barcode-list.ru разрешает публичный поиск названий, но не присылает заголовок CORS для чтения ответа браузерным приложением. Изменение настроек камеры или разрешений iPhone это не исправляет. Скрипт `barcode-worker.mjs` получает страницу на сервере и возвращает только название точного штрихкода и ссылку на источник. Он не ищет КБЖУ на произвольных сайтах и не подставляет их по догадке.

## Однократная настройка с iPhone

1. Войти или зарегистрироваться в https://dash.cloudflare.com/ и открыть Workers & Pages. Создать Worker, открыть редактор и заменить пример целиком содержимым `barcode-worker.mjs`. Это один файл, сборка и компьютер не нужны. Опубликовать Worker.
2. В настройках Worker добавить секрет `ACCESS_TOKEN`: свой случайный ключ из 32 или более латинских букв, цифр, `-` и `_`. Не использовать пароль аккаунта. При желании задать `ALLOWED_ORIGIN=https://z54f8pt489-bit.github.io` (это значение уже используется по умолчанию). Сохранить изменения. Ключ не добавлять в GitHub.
3. В «Теле» открыть Настройки → Российский онлайн-поиск → Подключение. Ввести адрес Worker вида `https://имя.поддомен.workers.dev` и тот же ключ. Нажать «Проверить и подключить». Успех показывается только после реального ответа сервера.

После настройки новые сканирования автоматически проверяют дополнительный источник, если основная база не вернула продукт. Повторные записи сохраняются прежним способом на iPhone, только после подтверждения пользователя.

Нужен доступ к своему аккаунту Cloudflare: из этой сессии он пока не подключён. Бесплатный план Workers имеет квоты; сверять условия в https://developers.cloudflare.com/workers/platform/pricing/ . Подключение источника не гарантирует наличие всех продуктов.

## Ограничения и проверка

- КБЖУ отсутствуют в Barcode-list.ru. При находке только названия приложение показывает пустые поля и просит цифры с этикетки. Оно не выдаёт нули за неизвестные значения.
- Разрешён только поиск валидного штрихкода. Произвольные адреса и содержимое дневника сервер не принимает. Все запросы требуют ключ.
- У источника указан Crawl-delay 10 секунд. Worker выдерживает интервал для новых запросов в одном экземпляре и кеширует карточки на сутки. Он предназначен для личного использования, не для массового сбора базы.
- Сервер не обходит ошибки доступа, CAPTCHA или ограничения источника. При изменении страницы возможна необходимость обновить разбор ответа.
- Проверки с сохранёнными примерами ответов не заменяют проверку размещённого Worker. Её необходимо выполнить после входа в Cloudflare и публикации.
