ПОРЦИЯ — PWA, автономная версия 1.0
===================================

В комплекте исходные файлы готового веб-приложения. Оно не требует Scriptable,
«Команд», TestFlight или Apple Developer Program.

КАК ЗАПУСТИТЬ НА IPHONE
----------------------
Приложению нужен HTTPS-адрес — Safari не устанавливает PWA непосредственно
из ZIP-архива или локального HTML-файла. Достаточно ОДИН РАЗ разместить содержимое
этой папки на бесплатном статическом хостинге (например, Netlify Drop,
Cloudflare Pages или GitHub Pages). Хостинг должен отдавать HTTPS.

После размещения:
1. Открой HTTPS-адрес в Safari на iPhone.
2. Нажми «Поделиться» → «На экран Домой» → «Добавить».
3. Запускай «Порцию» через её значок. Окно не будет требовать Scriptable.
4. При первом запуске сканера выбери «Разрешить» для доступа к камере.

ДАННЫЕ И БЕЗОПАСНОСТЬ
--------------------
- Дневник, вес, рецепты и фотографии хранятся ЛОКАЛЬНО на устройстве в IndexedDB.
- Приложение отправляет в Open Food Facts только название продукта либо штрихкод,
  когда ты используешь интернет-поиск.
- Сохраняй резервную копию через Настройки → Скачать резервную копию.
- Удаление данных Safari/сайта может удалить дневник, а режим приватного просмотра
  не предназначен для постоянного хранения.
- Данные из Scriptable не копируются автоматически из-за изоляции приложений.
  В Scriptable в версии 2.6 открой Настройки и создай JSON-копию,
  затем в этой PWA Настройки → Восстановить из копии.
- Изменение домена сайта означает отдельное браузерное хранилище: при смене адреса
  экспортируй и импортируй резервную копию вручную.

ОГРАНИЧЕНИЯ
-----------
- Нет публикации в TestFlight. Для неё необходим оплаченный аккаунт разработчика
  у владельца либо у третьего лица, согласного разместить приложение.
- Онлайн-поиск требует доступа к Open Food Facts. Доступность API из России и CORS
  необходимо проверить на самом телефоне.
- Сканер использует камеру и программный декодер EAN-8/EAN-13. На разных iPhone
  результат зависит от освещения, фокуса и версии iOS; 100% гарантия не заявляется.
- У веб-приложения системные разрешения камеры зависят от настроек Safari/iOS.

КАТАЛОГ
-------
Приложение включает справочные значения распространённых продуктов и блюда
из предыдущей версии, а для упаковок использует бесплатный Open Food Facts.
Источники не гарантируют полного ассортимента России.

СОСТАВ
------
index.html          — интерфейс дневника из «Порция 2.6»
pwa-bridge.js       — хранение и поиск без Scriptable
manifest.webmanifest — иконка и параметры установки
sw.js               — автономная работа интерфейса
icon-*.png          — значки

Никаких API-ключей или оплаты нет.
